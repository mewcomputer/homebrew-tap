# Mew Homebrew tap

Install the [Mew](https://mew.computer) CLI on macOS or Linux.

```sh
brew tap mewcomputer/tap
brew install mewcomputer/tap/mew
```

Upgrade with `brew upgrade mewcomputer/tap/mew`. The formula currently
installs a pinned nightly snapshot. Linux builds require glibc 2.39 or later.

See the [installation guide](https://mew.computer/docs/getting-started/installation/)
for other ways to install Mew.
